# 小说设定集 · 11 世界圣经 · 六原力本源（Six Cosmic Forces）

> 本作宇宙观的**常量层**。六力无善恶、不分正邪，只是按各自本能改造宇宙——这是全书世界观总纲，主角团 / 三队 / 反派势力的力量底色均源于此。  
> **官方锚点**：魔兽「初诞者（First Ones / Progenitors）」设定中，宇宙由**六大基础力量**构成——光明、虚空、秩序、混乱、生命、死亡——并设想了体现它们意志的万神殿。本作直接沿用这一六力框架，但**去掉官设中"光=善 / 虚=恶"的叙事着色**，把六力当作无善恶的宇宙常量（呼应 `07` §零总纲）。  
> 关联：`07-主角团技能组与灵能规则`（六属性灵能、抗性相克、生命灵能基线）｜`12-位面地理志`（各界灵能环境）｜`13-重大事件节点`（时间线）｜`14-反派势力图鉴`。

## 一、总纲：六种力量是宇宙常量

| # | 力量 | 英文                    | 官方对应面             | 本能倾向        |
| - | -- | --------------------- | ----------------- | ----------- |
| 1 | 虚空 | Void / Shadow         | Shadow magic      | 吞噬、侵蚀、归于虚无  |
| 2 | 圣光 | Light / Holy          | Holy magic        | 凝聚、秩序化、扩张光明 |
| 3 | 生命 | Life / Nature         | Nature magic      | 生长、焕新、繁衍    |
| 4 | 死亡 | Death / Necromancy    | Necromantic magic | 熵增、衰朽、归于静止  |
| 5 | 秩序 | Order / Arcane        | Arcane magic      | 塑形、精确、构建结构  |
| 6 | 混沌 | Chaos / Fel（Disorder） | Fel magic         | 破坏、无序、燃烧吞噬  |

**三相克对（呼应 `07` §1.13）**：

- 圣光 ⇄ 虚空（彼此最根源的对立；官设称"一者不能脱离另一者存在"）
- 生命 ⇄ 死亡（生长与熵增的循环两端）
- 秩序 ⇄ 混沌（塑形与崩解的张力）

**第七原力（官设留白，可作伏笔）**：初诞者框架中"六大基础原力之和、平衡者"被称为第七原力（Seventh Force）；本作可将其作为后期"宇宙平衡 / 观星者号真正用途"的潜在伏笔，**目前不展开、不绑定具体角色**。

> 叙事原则：六力本身不携带道德。是"使用者的目的"赋予行动善恶色彩——这也是影财团（灰）、衔尾蛇（暗）、近卫之手（光）三队光谱能在同一世界观下并存的根本原因。

## 二、六力分章

> 每力按「渊源 / 本质 / 已知掌控者 / 各界表现 / 相克细节」五栏展开。掌控者分两类标注：**【官】**= 官方宇宙实体；**【书】**= 本书角色 / 势力。

### 2.1 虚空（Void）

- **渊源**：虚空是实体宇宙之外的"无"——一片没有物质、只有潜能的黑暗海洋。官设中**虚空领主（Void Lords）**栖居其中，并造出**古神（Old Gods）**作为腐蚀实体宇宙的触手。
- **本质**：吞噬与侵蚀。虚空不"创造"，而是把已有的东西拉回虚无；它渴望吞没光明、填满自身。
- **已知掌控者**：
  - 【官】虚空领主、古神、萨拉塔斯（虚空神器意志）
  - 【书】梅丹佐（虚空编织者）、埃尔（虚空底色）、布拉格斯（衔尾蛇，虚空+暮光）、暮光之锤（投虚空的疯子）
- **各界表现**：
  - 艾泽拉斯：暗影魔法、古神低语、暮光之锤邪教
  - 扭曲虚空：混沌的能量乱流，实体生物难以久留
  - 乌尔纳（星际）：梅丹佐在此误入虚空乱流、借观星者号返航
- **虚空原质（Void Prime）· E-22 §十 引入（泰瑞尔命名）**：泰瑞尔指梅丹佐体内之物即"**虚空原质**"，并给出本书迄今最完整的宇宙生成表述——**"宇宙中最初只有时间；物质随时间的流转，吸收能量的成为虚空，散发能量的成为圣光"**。要点：**虚空与圣光是同一东西的两头**（一个往里收，一个往外放），无先后、无对错、无善恶。此为作者对六原力体系的**由角色之口说出的阐释**，非新增设定，与本节"六力无善恶"总纲同源。
- **虚空是"饿的"，不是"空的"（E-22 §十一 泰瑞尔）**：放逐进虚空的东西不是消失，是**被吃掉**——"**海会喝东西**"。它吸收的是**纯粹的、没有落点的情绪**（墨菲斯托的憎恨即是）；**有落点的情绪（如莉莉丝"保护人类"）它消化不了**。⚠️ 吃掉憎恨之后，虚空"**学会了**"——即 `13` E-09 中由憎恨孕生的**新古神**（与 `E-10` 萨拉塔斯所说"情绪自身孕育的更邪恶古神"、E-22 梅丹佐的体感**三方互证**）。
- **此界虚空"更粘稠"（E-22 §十一 梅丹佐体感）**：庇护之地的虚空比梅丹佐原本位面的更稠（"**像一碗脱水的粥**"），且存在**一层粘稠的薄膜隔绝现实与虚空**，薄膜以外孕育着某种东西。
- **相克细节**：与**圣光**直接冲突——虚空伤打圣光护盾时，护盾需消耗自身去"中和"虚空，消耗更快（`07` §1.14）。虚空系独有**反噬**危险：无节制驾驭会被虚空侵蚀心智（暮光之锤即例，`07` §1.7）。

- ★★ **虚空之下的四大派系（作者 2026-10-31 定）**
  - ⚠️ **层级关系（务必记清）**：**虚空＝原力统称**；其下四个派系——**熵能／深渊／古神／暗影**——**都是虚空灵能的分支**，彼此平级。
  - ⚠️ **"宇宙"一词已废**（作者 2026-10-31：原用"虚空（宇宙）"指本源派，词不好）⇒ **改为「熵能」**。
    - 改名依据：官设命名本就用"熵"给虚空系命名——**熵魔（Entropius，穆鲁被虚空腐化之态）／熵能之拥（虚空精灵种族技能）／熵能裂隙（11.0 暗牧虚空编织者英雄天赋基础技）**。
    - 且"熵"与这一派的能力对得上：**熵＝有序之物不可逆地散掉**，而此派擅长**瓦解、湮灭、破坏**。

  | 派系 | 本质 | 擅长 |
  |---|---|---|
  | **熵能** | 虚空派系（原"宇宙"派） | **瓦解、湮灭、破坏** |
  | **深渊** | 虚空派系 | **吞噬与控制**（相比破坏） |
  | **古神（腐化）** | 虚空万神殿的血肉构造体 | **精神攻击**，可腐化精神／灵魂 |
  | **暗影** | 虚空的一种灵能结构 | **泛用性最强、高兼容性** |

  - ★★ **关键区别：只有「暗影」不需要虚空灵能驱动就能用**——这是它泛用性的根源。所以：
    - 暗牧用暗影魔法、DK 有暗影伤害、术士用暗影魔法、敏锐贼有暗影伤害——**这些不是"走虚空派"，是暗影这一路的通用表现**。
    - **马蒂考尔体内的暗影烈焰**同理：不需要虚空灵能驱动。
  - ⚠️ **四派无高低强弱之分**，只是性质与用途不同。

### 2.2 圣光（Light）

- **渊源**：与虚空同源、同为本源两极。官设中**纳鲁（Naaru）**是纯粹的圣光能量体，圣光信徒（圣骑士、牧师）借其力。
- **本质**：凝聚与扩张。圣光倾向把无序收束、把存在"点亮"；但**过度纯粹的圣光亦危险**——纳鲁若堕入虚空会化为暗影（印证"无善恶"）。
- **已知掌控者**：
  - 【官】纳鲁、圣光密教、白银之手
  - 【书】格瑞恩（近卫之手，自创"光辉灵能"=圣光+火焰）、南希（戒律牧）、白银之手背景
- **各界表现**：
  - 艾泽拉斯：圣骑士/牧师之道、纳鲁造物（如维伦的圣光）
  - 官设对照：纳鲁本为善良能量体，但本书强调"圣光本能≠道德"
- **相克细节**：与**虚空**互斥（见 2.1）。**虚空印记**可被圣光灵能驱散技能清除（`07` 梅丹佐虚空齐射）。

### 2.3 生命（Life）

- **渊源**：与死亡同属"生与死无尽循环"（初诞者将其设为造物核心）。官设中**野性之神（Wild Gods）**、翡翠梦境为生命之力的具象。
- **本质**：生长、焕新、繁衍。生命灵能是所有活物的**底层基线**（`07` §1.5）。
- **已知掌控者**：
  - 【官】野性之神、德鲁伊传统、翡翠梦境
  - 【书】蕾娜（衔尾蛇，生命+死亡双系）、乔非（武僧真气≈生命灵能）、德鲁伊/萨满角色
- **各界表现**：
  - 艾泽拉斯：德鲁伊自然魔法、萨满引导自然灵能（路径 B，`07` §1.10）
  - 诺克萨斯（符文之地）：以**纯粹生命灵能掌握者**著称，生物能体系（见 `07` §1.5 伏笔）
- **相克细节**：与**死亡**互为循环两端——死亡系（骨语女士）将死亡之力转化为生命灵能驱动亡灵肉体（`07` §1.5）。相对灵能（虚空⇄圣光）吸收需**生命灵能中转**（`07` §1.16）。

### 2.4 死亡（Death）

- **渊源**：与生命同源，是熵增与衰朽的必然力量。官设中**典狱长（Jailer）**、暗影界、天灾为死亡之力的代表。
- **本质**：熵增、归于静止。死亡不是"终结"，而是把存在拉向静止态——与生命生长相对。
- **已知掌控者**：
  - 【官】典狱长、巫妖王、黑锋骑士团传统
  - 【书】骨语女士（邪 DK·萨莱茵）、被遗忘者（迈尔斯·科林）、蕾娜（生+死双系）
- **各界表现**：
  - 艾泽拉斯：死灵法术、亡灵天灾、黑锋之门召唤
  - 庇护之地（暗黑）：死灵法师（祖尔，骨语女士向其学白骨护甲）
- **相克细节**：与**生命**循环互补（见 2.3）。亡灵体内仍由（再构成的）生命灵能驱动，故可被正常按生命灵能波形锁定（`07` §1.4/1.5）。

### 2.5 秩序（Order）

- **渊源**：实体宇宙的塑形之力。官设中**泰坦（Titans）**是秩序的化身，奥术（Arcane）= 泰坦的"生命之血"，经**魔网（Ley Lines）**遍布世界。
- **本质**：精确、构建、结构。奥术本身"先天不稳定，驾驭需极高专注与精度"。
- **已知掌控者**：
  - 【官】泰坦、万神殿、奥术师、达拉然
  - 【书】海琳（近卫之手，奥术弓）、巴林（大法师三系）、休斯（符文禁锢）、法师系角色
- **各界表现**：
  - 艾泽拉斯：奥术魔法、魔网、法师塔
  - 元素魔法路径 A：以秩序灵能（奥术）**重构**化出火/冰/电（`07` §1.10）
- **相克细节**：与**混沌（邪能）**直接对立——奥术与邪能互斥（官设：邪能是秩序的崩坏显化）。同属"结构 vs 崩解"张力。

### 2.6 混沌（Chaos / Fel / Disorder）

- **渊源**：秩序的崩坏显化。官设中**邪能（Fel）**由**萨格拉斯（Sargeras）**堕落引燃，燃烧军团以邪能焚毁世界、汲取生命。
- **本质**：无序、破坏、燃烧吞噬。邪能"高度破坏、极易成瘾，靠抽取活物生命为燃料"。
- **已知掌控者**：
  - 【官】萨格拉斯、燃烧军团、邪兽人、恶魔
  - 【书】马蒂考尔（恶魔使徒，力源=庇护之地燃烧地狱）、奥里斯（复仇 DH，邪能）、埃尔（混沌/邪能底子）
- **各界表现**：
  - 艾泽拉斯：恶魔猎手、术士、邪能绿火
  - 庇护之地（暗黑）：**燃烧地狱（Burning Hells）**——马蒂考尔力量真正源头（自设偏差，见 `10` 八表）
  - 扭曲虚空：混沌裂隙召唤恶魔（马蒂考尔，`07` §1.3）
- **相克细节**：与**秩序（奥术）**互斥（见 2.5）。混沌系召唤需**统御之力**压制恶魔（`07` §1.3 马蒂考尔）。

## 三、抗性相克体系（指向 `07` §1.13）

| 相克对     | 含义         | 实战体现                      |
| ------- | ---------- | ------------------------- |
| 圣光 ⇄ 虚空 | 最根源对立，互斥最强 | 虚空伤打圣光护盾→快耗中和；虚空印记可被圣光驱散  |
| 生命 ⇄ 死亡 | 循环两端       | 亡灵以死亡转生命灵能驱动；相对灵能吸需生命灵能中转 |
| 秩序 ⇄ 混沌 | 塑形 vs 崩解   | 奥术与邪能互斥；同属"结构与瓦解"的张力      |

- **抗性本质**：抗性 = 自身对某灵能的掌握度（`07` §1.13）。同属性使用者天然高抗（梅丹佐对虚空抗性高）。
- **护盾中和**（`07` §1.14）：同类型吸收慢耗、相对类型快耗；不设固定减伤数值。
- **吸收中转**（`07` §1.16）：同类型直吸；相对灵能（虚空⇄圣光）须经生命灵能中转。

## 四、六力与"灵能"统一称谓（指向 `07` §零/1.1）

- 本作把所有魔法 / 能量统称**灵能**，参照星际幽能（可被感知、有波形、会透支）。
- 六属性灵能分支：虚空灵能、混沌灵能（邪能）、生命灵能、死亡灵能、圣光灵能、秩序灵能。
- **生命灵能是底层基线**：所有活物体内必有，与六属性灵能不冲突（法师走路用生命灵能、搓法用虚空灵能）。
- "魔法"是 natives 的俗称，机制层都是"汇聚某属性灵能"（`07` §1.6）。
