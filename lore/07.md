## 零、总纲：真实化战斗原则

1. **不无脑轰炸**：技能需要"蓄力 / 引导 / 锁定 / 冷却"，不能像游戏中随手甩。
2. **能量统一为"灵能"**：本作所有魔法 / 能量统称**灵能**，参照星际的幽能（灵能）设定——比魔兽魔法更接近"可被感知、会透支、有波形"的真实体系。
3. 必须考虑三件事：**召唤来源**、**技能 CD（= 灵能恢复）**、**瞄准锁定（= 灵能波形）**。
4. **技能不是"学会"的，是"搭出来"的**（作者 2026-10-14 定）：任何一种术法都由若干可调维度组合而成，长期取舍与定型才形成一个人的**风格** ⇒ **写提升＝写手艺（活儿细了／省了／快了／稳了），不是境界（修为精进／实力暴涨）**。详见下方 **§0.4 技能的构造维度**。

### 0.4 技能的构造维度（作者 2026-10-14 定）

> **总纲**：人物的技能不是像游戏里点一下"学会"，也不是捡到秘籍就顿悟——任何一种术法都是**若干个可调维度组合出来的结果**；长期的取舍与定型，才形成一个人独有的**风格**。
> 类比作者原话：**一个格斗家会不同的拳技、腿法、步法，对这些不同的组合，才形成自己的风格与技艺。**
> **数学类比（作者原话）**：基底就像现实世界的数学公式——**由一个公式可以延伸出多个公式**；魔法构建的本质就是数学，是对基础结构的持续延展与开阔。⇒ 因此古老的传承文本往往不是"招式清单"，而是别人的**推导过程**——看得慢，且照着往下推有可能推错（见注③）。
> ⚠️ **例外**：**卷轴**（§1.2）与**附魔装备**（§1.8）＝别人搭好并封装成型的成品，可以直接获得与使用；但获得的是**成品**，**不构成使用者自己的理解**。

- **注 ②（怎么"搭"：基底 ＋ 零件）**：上表第 3 项＝**基底**（作者原话："类似一个数学公式，或者一副骨架"）；其余各维度＝**零件**。⇒ **在标准基底上改流转、改波动、改时序……即可长出新东西。**
  - **衍生新技能的三条路**：
    1. **基底 ＋ 零件**：在标准骨架上调某一格（如把虚空冲击的时序压短、给输出模型换一套耦合形态）。
    2. **双基底拼接**：把两块基底接起来再补新的引导段（如把**虚空冲击**与**心灵震爆**接合）——接得越生，威力越难控。
    3. **借他山之玉**：看到别家职阶／体系的某个技能，获得**对自己灵能的新理解**，再回到自己的基底上重建。
  - ⚠️ 第 3 条的红线：**借的是思路与启发，不是力量本身** ⇒ 可写"借鉴"，**不可写成他在练别家的那套**。
  - 一句话总结（作者原话意译）：**学习＝搭积木——有基底、有零件，才谈得上搭建；不是开箱即得。**
- **注 ③（研发有风险 · 核心）**：作者原话——"**就像研究员研究药物、炸弹。**"⇒ **调试新结构＝在自己身上试**：改动生效的地方包括施法者本人，失败时先炸的是自己。
  - ⇒ **这是本书"提升必须慢"的根本原因**：不是不敢快，是**每一次微调都可能反噬自身**，所以老手宁肯把一段骨头啃上几个月，也不肯一次推到底（承接 §1.7 灵能耗尽／虚空反噬＝精神腐蚀）。
  - ⇒ 正文写"某人试新东西"，须同时给出**他要付的代价**，不许出现"试成了还没事"这种白捡。
- **注 ④（没有无敌 · 作者口径 · 必读）**：
  - 上表各维度**不是天赋等级，是每一个施法者都必须掌握的基本功**；人与人之间的差别＝**擅长的经度不同**（体现在同一基底上的参数偏好不同），**不是强弱不同**。
  - 作者原话举例：同一个「虚空齐射」，甲的空间延展缩放参数可能是 1.2、乙可能是 1.8——**参数不同不等于高下**。
  - ⇒ **本书不存在无敌的技能，也不存在无敌的人**。技能的多寡、投入的大小、范围的宽窄**都不决定胜负**；技能只是**把战局往自己想要的方向推一把的辅助**，真正决定结果的是**当场怎么用、用在哪一件要紧的事上**。作者原话：**"一个只会暗影箭的邪术士，也可能打败会很多技能的法师。"**
  - ⚠️ **写作禁令**：不写"这招更强／更高级／高下立判"这类层级判断；胜负要落在**选择与时机**（写清楚"在哪一个维度上被撬动了"），而不是"谁的等级高、技能多"。
  - ⚠️ **待作者定（我提的，不是口径）**：本文件技能表现有的类型标签"**终极**"（虚空形态／虚空湮灭／血肉巨兽等）容易被读成"更强"；建议改称"**重投入**"（＝极高耗、结束后虚弱），或保留标签并加一句说明。
- **注 ①（防撞词 · 必读）**：上表第 2、6 条的"**环节**"＝**灵能结构内部的分配／激活单元**（抽象的分配节点）。⚠️ **勿与 §1.14 物理护甲上的"灵能节点"混用**——后者是装备上真实存在的承力点（灵能纹路把动能分散过去吸收），两者不是一回事。
- **写作提醒**：正文写"某人进步"，落点是**手上某一格被修好了**（同样的灵能打出去更实／能把一记压成更短的一瞬／隔一间舱就辨得出波形／同一件事少缓半口气），**不写数值、不写"他的力量更凝练了"这类抽象句**。

## 一、灵能系统（通用规则）

### 1.1 能量统一为灵能

- 本作所有能量 / 魔法统一称"灵能"。
- 按六种力量属性的灵能分支：**虚空灵能、混沌灵能（邪能）、生命灵能、死亡灵能、圣光灵能、秩序灵能**。
- 参照：星际的灵能（幽能）设定——可被感知、有强弱、会透支、带个体波形，比魔兽魔法更"真实"。

### 1.2 技能 CD = 灵能恢复耗时（且由使用者自行决定投入）

| 规则 | 说明 |
|---|---|
| 本质 | 释放技能消耗灵能；"CD"就是消耗掉的灵能恢复到可用所需的时间 |
| **投入可变** | **真实环境中，使用者可自行决定本次投入多少灵能**——投入越多，技能杀伤/效果越强，但 CD 越长；投入越少，威力越弱、CD 越短 |
| 对练模式 | 训练 / 切磋时可把灵能投入压到**最低**，从而大幅降低甚至消除杀伤力（如观星者号对战模拟室） |
| CD 时长 | 因此**不存在固定数值 CD**：同一技能在不同情境下 CD 不同，取决于当场投入 |
| 卷轴类技能 | **无 CD**，但每次使用消耗一张卷轴（一次性资源）；形态类似 DnD 纸卷——技能符写在纸上，用后卷轴消失 |

> 作者说明：正因为"投入量由人决定"，本作**不预设每个技能的固定灵能消耗数值**——数字会随情境、情绪、战况浮动。写正文时按"轻点 / 重砸"的语义描述即可，不必填表。
> 抗性与投入不冲突：二者是**两个独立维度**。**投入量**是使用者主观决定"技能打出去多少威力"；**抗性**是目标侧决定"打在身上被减免多少"。所以"无视抗性"指该技能无视目标的减伤，与投入量大小无关——不存在冲突。

### 1.3 召唤技能规则

| 角色 | 召唤方式 | 说明 |
|---|---|---|
| 梅丹佐 | 虚空裂隙（**决定不添加召唤技能**） | 虚空危险性高于燃烧地狱，未知会召出什么；曾设想"虚空裂隙弹幕"（参考军团再临毁灭术士次元裂隙），但与**虚空齐射**重合度过高，故放弃。留坑保留为"无召唤"——队伍已有马蒂考尔地狱犬、骨语女士憎恶/爪牙/血肉巨兽，召唤足够多 |
| 马蒂考尔 | 混沌裂隙 | 可召唤恶魔；因对恶魔有**统御之力**，能压制恶魔、令其听令 |
| 骨语女士 | 黑锋之门 | 召唤物从黑锋之门中出来；**三头骸骨狮鹫例外**——重铸类，以狮鹫遗骸当场重铸成形，此后可召唤／收回，不走门（见 §五） |

### 1.4 目标锁定（瞄准）规则

- 通过**锁定**目标，才能让技能准确打击对方。
- 可用**瞄准辅助类工具**辅助锁定，更易锁住目标。形态类似**护目镜 / 夜视仪**——可识别并读取对方的能量波形，辅助完成锁定。
- **锁定原理**：锁定对方的**能量波形**（广义）。
  - **活物**：体内必有生命灵能（生物能），波形各不相同，据此锁定。
  - **机械 / 构造体**：若有能量驱动（能量核心、蒸汽热源等），会发出能量波动，同样可按其**能量波形**锁定。
  - **纯无能源机械**（如单纯齿轮结构）：无能量波动，**无法锁定**——但实战中几乎不存在靠纯齿轮构成的真正作战单位（连蒸汽动力也有热源波动）。
- **不完美（真实化）**：会出现**目标脱离**或**误伤**——所以不存在游戏中"无脑技能必中"的情况。
- **波形显现与锁定代价（补充，见 §1.17）**：灵能波形**仅在消耗灵能时显现**；且用灵能锁定目标本身也**消耗灵能**，故非战斗状态不会无谓锁定他人。

### 1.5 生命灵能（生命原力）

- **定义**：只要是活物，体内必有**生命灵能**（也称生命原力）——即现实中的"生物能"。
- **日常使用**：人类挥拳、跑步都在消耗生命灵能，只是强弱因掌握程度而异；掌握越强，肉体与物理打击越强。
- **魔兽对照**：战士的"血怒"在本作归类为**生命灵能的激发运用**——靠生物能爆发强化肉体，而非外援魔法。
- **关键作用**：生命灵能强化**肉体与物理打击**，因此**没有魔法（圣光 / 虚空 / 秩序-奥术等灵能）的角色，也能与施法者打得五五开**——解决了"物理职业打不过法师"的常见失衡。
- **与六种力量灵能的关系**：生命灵能是**所有活物的底层基线**；虚空 / 混沌 / 死亡 / 圣光 / 秩序等是觉醒 / 后天掌握的属性灵能。一个法师走路用生命灵能，搓法术用虚空灵能——二者不冲突。
- **亡灵的能量来源（死亡之力 → 生命灵能）**：被复生者（如骨语女士、被遗忘者及后续亡灵生物）并非直接以死亡灵能驱动肉体，而是将**死亡之力转化为生命灵能**来驱动自身。因此他们体内依然有（再构成的）生命灵能，可被正常按生命灵能波形锁定；其本质来源是死亡之力（见 1.4）。
- **剧情伏笔**：后期将设计**符文之地·诺克萨斯进攻艾泽拉斯**，诺克萨斯人物均为**生命灵能掌握者**——以纯粹生物能体系与艾泽拉斯的灵能施法文明碰撞。

### 1.6 "魔法"的定义（in-world 称谓）

- **机制定义**：凡需要**引导 / 汇聚灵能**才能释放的技能，机制上都算"魔法"。
- **艾泽拉斯视角**：以艾泽拉斯生物为例，他们不理解灵能的运行逻辑，故把所有引导灵能的技能**统称为"魔法"**——"魔法"是 natives 的俗称，不是机制分类。
- **含义**：同一个"魔法"动作，在机制层是"汇聚某属性灵能"，在叙事层被不同世界叫不同名字（魔法 / 术法 / 灵能技艺等）。

> 作者说明（跨作品）：本书强调**诺克萨斯以生命灵能掌握者著称**（其强者多为生物能体系），用以解释生命灵能体系的强度；但符文之地整体**仍有各类灵能施法者**（消耗虚空 / 混沌 / 圣光等灵能），与生命灵能体系不冲突。诺克萨斯入侵艾泽拉斯的跨世界剧情，即以"生物能文明 vs 灵能施法文明"的差异为底色。

### 1.7 灵能耗尽（通用）与 虚空反噬（虚空专属）

必须区分两个常被混为一谈的概念：

- **灵能耗尽（通用机制，所有属性）**：灵能类似现实中的体力——任何人持续或过度使用都会耗尽。
  - 例：梅丹佐即便用最基础的**虚空冲击**，若一次性投入全部虚空灵能，也会**灵能耗尽**；埃尔持续战斗、反复使用**眼棱**，同样会耗尽自身灵能。
  - 这是"体力"类比：耗尽后无法再释放，只能等灵能恢复（即 CD 的本质——恢复耗掉的灵能）。
  - **灵能恢复手段**：① 自然恢复（即 CD 本质）；② **能量药剂**（类比魔兽回蓝药，直接补充灵能池——如梅丹佐虚空形态结束后的虚弱期需用药剂回升）。
  - **适用所有人**：虚空 / 混沌 / 死亡 / 生命等属性施法者都会灵能耗尽，与属性无关。
  - ⚠️ **措辞**：灵能储在体内不在手上 ⇒ 禁写"手上没底了"，写"体内／自身灵能耗尽"（详见 §1.19 末）。
  - ★★ **直观症状＝心悸、心慌（作者 2026-11-06 定·写"灵能见底"必读）**：
    - 灵能消耗或枯竭时，最直接的体感是**心悸、心慌**，不是"看数值"，也不是"光变弱"。
    - **所以"恢复"要写成症状消退**：药咽下去、在胃里化开、深呼吸几口，那股心悸慢慢退下去 ⇒ 读者据此知道灵能在回来。
    - ⇒ **禁写**"感觉到灵能在一点点恢复／慢得能数出来"这类进度条式描写。判断余量靠**身体**，不靠读数。
    - 同理：灵能见底的人**召得出护甲**，只是心里发慌、手上发虚（§1.19"消耗≠耗尽"）。
- **虚空反噬（虚空灵能专属危险）**：仅当使用**虚空灵能**且无节制时，虚空会反向**侵蚀使用者心智**。
  - 机制：虚空是无情而可怕的力量，无节制驾驭会被其同化、影响神智。
  - 例证：**暮光之锤（Twilight's Hammer）**投靠虚空、借用古神（Old God）之力故实力强，代价是已沦为**虚空的疯子**。
  - 与"灵能耗尽"区分：耗尽是体力层面（谁都会），反噬是虚空特有的**精神腐蚀**（仅虚空系有）。

### 1.8 附魔技能（储能式 / 电池模型）

- **定义**：在武器 / 装备上**符刻**某个技能，装备可直接释放该技能，**不消耗使用者自身灵能**。
- **原理**：灵能已预先**注入装备**（像一块电池）；释放时消耗的是装备里存好的灵能，而非施法者。
- **电池模型**：装备所储灵能耗尽 → 该技能放不出，需**充能**（重新注入灵能）才能再用。
- **与施法技能的关键区别**：附魔技能**单次威力恒定**——因为储能固定，不像施法者那样可调投入（见 1.2）。
- **例**：一把**符文剑**，每次攻击释放一道剑气，每道耗 **30 灵能**，剑总储 **300 灵能** → 可释放 **10 次**，用尽需充能。

> 技能交付三类对照：
> | 类别 | 灵能来源 | CD / 限制 | 威力 |
> |---|---|---|---|
> | 施法技能 | 消耗自身灵能 | CD = 灵能恢复耗时（可变投入） | 随投入浮动 |
> | 卷轴技能 | 消耗卷轴（纸） | 无 CD，卷轴一次性 | 卷轴定值 |
> | 附魔技能 | 消耗装备储能 | 无 CD，储能耗尽需充能 | 单次恒定 |

### 1.9 远程 / 实体武器附魔（枪械 · 弓箭）

- **设计目的**：解释为何"用枪械、弓箭的人"能与施法者、生命灵能高强的角色**战力相当**——他们不走"消耗自身灵能池"的路线，而是靠**附魔弹药 + 精准 + 物理打击**持续作战。
- **两类武器，两种附魔逻辑**：
  - **① 实体弹药型（有真实子弹 / 箭矢）**：附魔作用在**弹药本身**。例：子弹浸泡圣水、在弹头刻符文。每发附带额外效果（灼烧 / 现形 / 破灵等），弹药为消耗品。
  - **② 能量武器型（无实体弹药）**：如能量炮、魔法弓（拉弓即自动生成箭矢）——**等同于 §1.8 附魔装备的"电池模型"**：每次射出的能量箭，消耗的是武器**预先注入的灵能**；装备品质越高 → 可承受（储存）的灵能越多 → 单次释放强度越高。
- **与三类交付的关系**：实体弹药附魔 ≈ 卷轴式"一次性消耗品"；能量武器 ≈ 附魔式"装备储能"。二者都**不烧使用者自身灵能池**，故物理系无需成为施法者也能与法师对线。

### 1.10 元素灵能（元素魔法的能量来源）

- **参照**：魔兽中元素魔法（风火水电）有两种获取方式——法师以**奥术**转化而来；萨满当**元素的仆人**，借用元素之力。
- **本书设定**：元素魔法即**元素灵能**，有**两条独立路径**，能量来源不同：
  - **路径 A · 秩序灵能（奥术）重构**（法师式）：精通**秩序灵能**者，可主动**重构其形态**，从而化出火 / 冰 / 电等元素技能。秩序灵能是"原料"，由施法者自己塑形。
  - **路径 B · 生命灵能引导自然灵能**（元素萨 / 元素使式）：因生命魔法在魔兽中的表现之一即**自然魔法**，故以**生命灵能**去**引导自然界中的灵能（自然魔法）**来使用；但**驱动自然灵能需消耗自身生命灵能**。
    - 此限制的意义：若不设消耗，等于无限借用天地灵能，过于超模；加上"耗自身生命灵能"这一上限，元素使 / 元素萨的能量来源才合理闭环。
- **要点**：同样叫"火球"，路径 A 烧的是秩序灵能（自我塑形），路径 B 烧的是自身生命灵能去调动外界自然灵能——写正文时按角色所属路径区分其消耗。

### 1.11 生物灵能与魔法生物亲和

- **总则（呼应 §1.5）**：所有生物体内都有**生命灵能**，这是活物基线。
- **魔法生物**：在生命灵能之外，有自身的**自然灵能亲和**。
  - 例：**喷火巨龙** = 自然灵能 · **火元素亲和**。
- **释放机制**：魔法生物每次释放天赋能力（如喷火），也是用**生命灵能去引导自然灵能**，将其转化为对应形态（火）。即魔法生物的天赋 ≈ 路径 B 的"亲和版"——亲和是天赋，引导仍消耗自身生命灵能。
- **意义**：把"龙息 / 元素生物天赋"也纳入同一套灵能经济，避免魔法生物凭空无限吐火；同时与 §1.5"生命灵能基线"完全自洽。

### 1.12 元素领主与元素构造体（自然灵能的具象化）

- **自然灵能的层级**：自然灵能（自然魔法）并非均匀分布，会按浓度 / 凝聚度具象出不同层级的实体。
- **元素领主（Elemental Lords）**：自然灵能产生**意识**后，**自主诞生的生命体**。
  - **设定保留**：元素魔法使用者**仍可借用元素领主的力量**（呼应魔兽萨满"当元素的仆人"传统）。这与 §1.10 路径 B"用生命灵能引导自然灵能"**不冲突**：借用领主之力是契约 / 借用关系，引导自然灵能是直接调动天地灵能，二者可并存。
- **元素构造体**（火元素 / 水元素等）：自然灵能**凝结**而成的元素体，**无高级思维**，但具备两种本能意识：
  - **领地意识**：对所属区域有守护 / 排斥本能；
  - **以自身力量影响现实的意识**：依本能运用本属元素力量改变周遭（如火焰焚烧、水流冲刷）。
- **与六大原力一致（呼应世界观总纲）**：元素领主与元素构造体的行为，与"六种力量（灵能）**无善恶**，仅按本能用自身力量改造现实"的总纲完全一致——它们既非善也非恶，只是在用自己那一份力量影响世界。

### 1.13 抗性体系

- **本质**：抗性 = 自身对某种**灵能的掌握度**。掌握度越高，对该灵能的抗性越高（受击减伤越多）。
- **各来源的增益方式**：
  - **生物**：精进自身**生命灵能** → 可提升对其他灵能的抗性（生命灵能是底层基线，强则泛用抗性上去）。
  - **非生命体 / 构造体**：无法精进生命灵能，需对**机体附魔**来加抗性。
  - **装备附魔**：在装备上附魔，可增加对各种灵能的抗性（人人可叠）。
  - **同属性使用者**：如梅丹佐是虚空灵能使用者，天然对**虚空**抗性更高（用得多 = 抗性强）。
- **六种灵能克制关系**（相克三对，呼应世界观总纲）：
  - 圣光 ⇄ 虚空 ｜ 生命 ⇄ 死亡 ｜ 秩序 ⇄ 混沌
  - 含义：相对属性的灵能彼此冲突 / 抵消更强（见 §1.14 护盾中和、§1.16 恢复中转）。

### 1.14 护盾与物理护甲

- **护盾（灵能护盾）**：由自身能量凝结而成，可**吸收灵能伤害**，但吸收有**上限**。
  - **同类型吸收（慢耗）**：如梅丹佐的虚空护盾吸收虚空伤害 → 消耗更慢（性质相合）。
  - **相对 / 异类型吸收（快耗）**：如用虚空伤害攻击**圣光**护盾 → 圣光护盾需消耗自身去**中和**虚空灵能 → 消耗更快（相克抵消）。
- **物理护甲（装备韧性 = 动能防护）**：装备经附魔后，可将受到的物理伤害（动能）**分散并吸收**：
  - 例：胸口受物理攻击，装备上的**灵能纹路**把冲击分散到各处**灵能节点**，由各节点吸收。
  - 每个灵能节点吸收有**上限**，超过上限则无法再吸收（溢出伤害照常生效）。
- **不设定具体减伤数值（真实化原则）**：本作**不设固定减伤% 或护盾血量数值**。类比现实穿防弹衣——你不知道它最多扛几枪，但知道扛不住巴雷特一击。战斗更依赖**随机应变、见招拆招**，而非查表。

### 1.15 灵能上限（不设固定数值 + 测试仪器）

- **不设精确上限**：灵能如同查克拉 / 人的体力——使用者**不知道自己的具体数值**，但每次消耗都能"感受"到灵能消长；也会在灵能耗尽后**爆种突破**自身。
- **测试仪器（可选工具）**：可配置检测设备，粗略测出自身灵能**大概上限**、以及某次技能释放**消耗了多少灵能**；但仪器只给**大概范围**，非精确值（仅作参考，不替代"体感"）。
- **结论**：正文不写"灵能值 = 1234"，按"体感 + 仪器粗测范围"描述即可。

### 1.16 治疗与恢复（灵能转化规则）

- **治疗（伤口治愈）**：以骨语女士**血箭**为例——吸收对方的**生命灵能**，转化为自身生命灵能；伤口愈合则是用某种灵能在伤口处快速聚集、转为生命灵能来修复。
- **恢复灵能（补自己灵能池）**：吸收对方的灵能，转为自己需要的灵能。按目标类型分两种：
  - **同类型灵能使用者**：直接吸收并转化（如虚空吸虚空，顺畅）。
  - **相对灵能（如虚空 ⇄ 圣光）**：**无法直接吸收相对灵能**——须先以**生命灵能**作为中转，将对方灵能经生命灵能转化后为自己所用。
- **与 §1.13 克制呼应**：相对属性不能直吸、需生命灵能中转，正是六力相克在"吸收"上的体现。

### 1.17 隐身、潜行与锁定消耗（含波形显现条件）

- **灵能波形显现条件（重要）**：**只有在消耗灵能时，才会显现出灵能波形**。不施法 / 不消耗灵能时波形基本不外露——天然降低平时被锁定风险。
- **锁定本身也消耗灵能**：用灵能锁定目标**要耗灵能**，所以**不会闲着没事去锁定别人**（非战斗状态不无谓锁定）。
- **隐身 / 潜行两类**：
  - **① 物理隐形**：扭曲光影，肉眼不可见；但**灵能波动仍会体现**——会被灵能感知 / 波形锁定抓到。
  - **② 高级隐形（物理 + 灵能遮蔽）**：在物理隐形外，**模拟自身灵能波形与自然界一致**，使对方无法锁定；但灵能遮蔽**有时间限制**，到期或一旦自身施法（现波形）即失效。
- **与 §1.4 一致**：锁定 = 读能量波形；波形不现则难锁，故潜行角色在"不施法 + 灵能遮蔽"期间极难被锁定。

### 1.18 装备品质

- 决定因素：**材料**、**制作精细度**、**装备上的灵能附魔**（储能上限 / 单次强度 / 抗性加成等，见 §1.8–§1.9、§1.13–§1.14）。
- 品质越高 → 可承受 / 储存的灵能越多、附魔效果越强。具体分级（普通 / 精良 / 史诗 / 传说等）作者可按剧情自定，本作不设硬性数值门槛。

### 1.19 灵能武装（Psi-Forged Armor）— 全职业通用

- **定义**：为解释"瞬间换装"的游戏机制、同时避免背行囊的观感，本书设定——**完整护甲不以实物携带，而是以灵能形态存储，需要时由灵能驱动实体化**。召唤与收起均在瞬息完成，护甲在灵能驱动下贴合身形，无需穿脱。
- **两种存储方式**（按角色灵能容量分）：

| 类型 | 适用 | 存储 | 优点 | 代价 |
|---|---|---|---|---|
| **灵能内储** | 灵能充裕者（施法 / 虚空系，如梅丹佐） | 自身灵能 | 无外物依赖、成形最快 | 占用灵能池；**灵能耗尽时护甲溃散** |
| **灵能外储** | 灵能较少者（工具型职业：猎人、战士、潜行者等） | 随身**灵能容器** | 不占自身灵能、成形稳定 | **容器可被击碎 / 耗尽**，失去后无法召唤 |

- **容器形态**：不限——胸口水晶、手镯、臂环、腰带扣、护符、指环、额饰等皆可，按角色与职业习惯选择（具体角色用何种容器，作者后续按人物定）。
- **平衡性**：内储怕灵能枯竭，外储怕容器损毁，两者互有优劣，不存在绝对强弱。
- ⚠️ **写法约束（作者 2026-10-12 命由 MEMORY 归入本档·写「灵能见底」必读）**：**灵能储在体内，不在手上**——灵能池长在施法者自己身上（内储），随身容器属外储 ⇒ **禁写「手上一点底不剩／手上没底了」**（那等于把灵能写成了握在手里的东西）。写耗尽时写**体内／自身灵能耗尽**，或按 §1.7 写「灵能耗尽后的恢复」；工具型职业的**灵能容器**同理，容器是随身物件（水晶／手镯／腰带扣等），也不在手上。
- **与 §1.7 呼应**：内储者护甲与自身灵能池共享上限——灵能耗尽（通用机制）时护甲随之溃散，是战斗中的真实风险点。
- **首例**：E-10 第五节，梅丹佐护甲自灵能中显形实体化（`小说正文/E-10`）。
- ★★ **定位澄清（作者 2026-11-06 口述·写战斗必读）**：**灵能护甲不是"战斗服"**，它不承担"穿上才能打"的功能；它的作用是**增益、强化、增幅，或提供某些特殊能力**。
  - ⇒ **可以只穿锚衣战斗**——战斗靠的是人物自己的能力，**不必依托护甲**。
  - ⇒ 写法影响：护甲不现形**不等于没装备、不等于变弱**；人物脱了护甲照样能打。护甲是**加成层**，不是**资格层**。
  - ⚠️ 由此作废一条我自己提的判据："能不能穿着它打一场"——**错**。那一问与锚衣无关（见 §1.19 锚衣节）。
- ★★ **修复对象＝锚点（作者 2026-11-06 定）**：
  - **护甲破损的实质是锚衣上的锚点受损**。所以修复做在**锚点**上，不是在空中补一团能量。
  - **锚点是什么**：缝在衬里、滚边、扣饰里的**晶体、水晶、符文、灵能丝线**（即 §② 说的"可附加物"）。
  - **怎么修**：向锚点重新灌注灵能，把裂纹稳住，护甲在该处才能重新成形。
  - **代价**：**修好的地方比原装脆，同一处还会再裂**——这是"只能凑合、不能复原"的物理原因。
  - **灵能见底时的症状**：锚点灌不进灵能 ⇒ 护甲在那一块**缺一块、发虚**。不是"护甲破了"，是"这块喂不饱"。
- ★★ **它不是"护盾"，是"甲"（作者 2026-11-06 纠）**：
  - 外形是**实体甲胄**——甲片、胸甲、肩甲、面甲、腰扣、垂布。**没有"薄薄一层/一层光膜/像霜"这种东西**。
  - 各人外观见 `01`／`08`／`09`：梅丹佐＝深蓝近黑的甲片（#1a1257）、甲缝流转**幽紫光**、胸前白蓝晶体（幽暗之心）、尖顶冠盔衬放射状黑刺、肩背张出**黑刃**、淡紫／藕荷色长布幅垂到脚面、小臂与腰侧露金色、**覆面含面甲**（面甲灵能纹路内流幽紫光）。
    - ⚠️ **光翼已取消，正文勿再写。**
  - **"灵能不足"的可见症状不是甲变薄，是"光走不过去"**：甲缝里的灵能流光在断处停住，或晶体一颗颗暗下去（先例：`09` 米露，E-70 §六）。
  - ⇒ **禁写**：薄如霜、一层、半透明护盾、光幕。
- ★★ **部分现形（作者 2026-11-06 定）**：灵能护甲**不必全身召出**，可以只要一部分。
  - 类比：**马蒂考尔的部分恶魔化**——同一种"局部调动"的思路。
  - 例：灵能不足时**只召胸甲**；或只留肩与前臂，其余收回。
  - **已有正文先例**：`09` 米露在暴雪中**只召面甲**挡雪粒，进村即解除（E-70 §六）。
  - ⚠️ **"消耗大部分"≠"耗尽"**：战斗打掉大半灵能的人，护甲照样召得出、扣得上，只是**流转不全**；只有真正**耗尽**才整体溃散（见 §1.7）。写"召不出来/召了就散"必须有耗尽的前提。
  - ⇒ 写法价值：护甲可以写出**"哪一块有、哪一块没有"**，比"有／没有"两种状态细得多。
- ★★ **锚衣离身 ⇒ 护甲无法维持（作者 2026-11-06 推出的必然结果）**：
  - 护甲靠锚衣上的锚点导出并稳住 ⇒ **脱下锚衣，护甲随之收回**。**脱衣＝卸甲**，是个现成的动作设计。
  - ⇒ 锚衣之下通常还有**素衣**（单薄、不保暖）⇒ **脱了锚衣的人会冷**。这是"锚衣＝外穿常服"的必然后果，也是写"冷"的正当理由。
- ★ **锚点材料：泪石（作者 2026-11-06 首次出现）**：
  - 一种常用晶体，可缝在锚点处。**崩了会留下发白的崩口**（不是"裂纹"，是"崩"）。
  - **碎了补不回来，只能换**；而"这东西现在弄不到"⇒ 天然构成补给压力。
  - ⚠️ 泪石的产地、价格、外观细节**尚未定**，AI 不得自行编造。

#### ★★ 锚衣（Anchor Suit）· 来历、演变与型制（作者 2026-11-02 口述·写人物着装必读）

> 背景设定，**战斗戏无需刻意展示**；但**写角色穿什么、换装、挑衣服时按本节写**。

**① 它因何而生**

- **锚衣是随着灵能护甲一同出现的**，如今是**最常见的日常装束**。
- **最早的形态**：使用者只穿一层内衬，再在其上附着灵能护甲；**当时的护甲是一直穿在身上的**。
  - 它不同于常规的外穿护甲——**需要使用者始终用灵能维持护甲的稳定性**。
  - ⇒ **长时间维持灵能护甲会加重灵能负担**。这是当初真正的痛点。
- **着装生态（作者 2026-09-28 定；★ 2026-11-02 修订）**：
  - **灵能护甲召唤现形时，没有灵能锚点的衣物会被撕碎**。
  - **大部分日常衣物自带灵能锚点**——夹克、长袖、长裤、鞋子等常见衣物都能承受护甲现形（即"锚衣"，锚＝锚点的锚），常召唤者日常穿着无碍。
  - ★★ **锚衣定位修订（作者 2026-11-02）**：**锚衣不是"打底的素衣内衬"，而是可以直接作为日常穿搭穿在外面的衣服。**
    - ⇒ **旧口径作废**：此前把锚衣理解为藏在护甲下面的一层素衣打底；**现口径＝它本身就是常服**，该讲究剪裁、面料、配色，能穿出门、能见人。
    - ⇒ **修订理由（作者原话）**："这个更加贴近了真实场景。"
    - ⚠️ 由此产生的写法变化：**写角色换装／着装时，锚衣按"外穿的衣服"写**（写它的样子、质感、合不合身），**不写"里面那层打底"**。
  - **无灵能锚点的衣服反而是奢侈品**：纯素面料、不经锚点处理，穿它的人要么从不召唤护甲、要么召一次毁一件——无锚衣＝身份与财力的象征（价格逻辑与现实相反）。
    - ⇒ **锚衣外穿化后，这条反差更成立**：**穿在外面的好看衣服若不是锚衣，一召唤就碎** ⇒ 敢把好衣服穿在外面的人，要么是有锚衣的常召唤者，要么是根本不用打架的贵人。
  - **亦有普通实体护甲正常穿脱**：掌握不了灵能召唤的人（如虚空投影**见习**、普通士兵/平民）就**正常穿戴实体护甲**，穿戴逻辑与现实无异。

**② 它怎么演变成今天这样**

- **第一代＝打底素衣**：人们开始考虑做一种"能承受灵能护甲"的衣服 ⇒ **最早的锚衣就是打底素衣**。
  - **代价**：召唤出灵能护甲后**会撕碎外衣**。
  - **收益**：解决了**必须长时间用灵能维持护甲**的问题 ⇒ 这是它当初被接受的原因。
  - ★★ **它为什么被淘汰（作者 2026-11-02 补）**：
    - **① 已停止生产** ⇒ 旧款是**存量旧物**，不是现役商品。

    - ⇒ 所以它不是"被新款挤掉的"，是**自身的稳定性上限到顶了**——好看只是导火索，不够稳才是死因。
    - ⚠️ **写法价值**：穿旧款的人，身上带着的是**一件随时可能不稳的东西**。这比"土"严重得多。

### 1.21 灵能施法的三种表现形态（作者 2026-09-30 口述·写施法场面必读）

> 前提（作者明）：**魔兽本身并没有"施法时能量怎么走"的具体表述**，本作灵能体系需要自己定一套**看得见的施法流程**。凡"需要汇聚能量再释放出去"的法术，一律按下述三种形态之一写。

| 形态 | 流程 | 样例 |
|---|---|---|
| **A 汇聚型（汇集→发射）** | 灵能**汇集在手中**，成势后发射出去 | **梅丹佐的虚空冲击**：虚空灵能汇集在手中，再打出去 |
| **B 生成增长型（生成→变大→投掷）** | 手张开，**一团能量在手中生成并不断变大**，到量后投掷出去 | 火球术：小火球在手中越变越大，最后掷出 |
| **C 包裹型（包裹手部→飞弹化投掷）** | 灵能**在手部聚集并包裹住整只手**，再以**飞弹**的形式投掷出去 | 灵能裹住手，甩出一道飞弹 |

- ⚠️ **三种形态的共同点＝"手"是整体（容器／载体），不是一个点**。⇒ 这从设定层面坐实了：**施法部位写"手中／手心里／手上"，不写"掌心"**。
  - A＝**捧着一团**（手中那个空间里）；B＝**手里长出来**；C＝**整只手被包住**（像戴了只手套），**都不是"手掌心那个点"**。
  - **作者原话（2026-09-30）**："**说到掌心，第一反应是他的手完全打开、能量在掌心中汇聚**"——但施法的手**很多时候是半握的**，这种时候就该写**"在手心里"或"手中"**。另："里"是容器、"心"是部位，精确指向手掌上一点＝穴位感／内功感＝仙侠味。
  - ❌ **旧章不回溯**（作者 2026-09-30 定："以前的地方就别改了"）：E-10～E-69 已写就的"掌心"**一律不动**，本条只约束**新写的内容**。
- ⇒ 由此可推的写法建议（AI 拟，待作者核）：C 类尤其适合写**包裹到小臂**、**指缝里漏光**、**甩出去时手上残留一层**；B 类适合写**越变越大撑得手指张开**、**迟迟不掷＝在蓄量**；A 类适合写**汇集时的抽感／周围空气被抽动**。

## 八、待确认

1. ✅ 各技能**固定灵能消耗数值**已决定**不设**——投入量由角色当场决定（见 1.2），正文按语义描述即可。
2. ✅ 已明确两概念区分：**灵能耗尽 = 通用机制**（任何人过度 / 持续用灵能都会耗尽，类比体力；梅丹佐全投虚空冲击、埃尔连甩眼棱皆会耗尽）；**虚空反噬 = 虚空专属**（无节制用虚空之力会侵蚀心智，暮光之锤借古神力变疯子即例）。故"过度投入必反噬"不成立，但"过度投入必耗尽"成立（通用）。**灵能上限已决定不设固定数值**（见 1.15）：灵能似查克拉 / 体力，靠体感 + 可选测试仪器粗测大概范围，不写精确值；灵能耗尽后可"爆种突破"。
3. ✅ 梅丹佐召唤技能**决定不添加**：曾设想"虚空裂隙弹幕"（参考军团再临毁灭术士次元裂隙），但与**虚空齐射**重合度过高而放弃；留坑保留为"无召唤"（队伍已有马蒂考尔地狱犬、骨语女士憎恶/爪牙/血肉巨兽，召唤足够多）。
4. ✅ **瞄准辅助工具**形态已定：类似护目镜 / 夜视仪，可识别并读取对方能量波形以辅助锁定（见 1.4）。
5. ✅ **卷轴技能**形态已定：DnD 式纸卷，技能符写在纸上，用后卷轴消失、无 CD（见 1.2 / 1.8 对照表）。主角团具体谁用、对应什么技能仍可后续分配。
6. ✅ **能量药剂**已定：类比魔兽回蓝药，直接补充灵能池（见 1.7）；梅丹佐虚空形态后虚弱期即用此回升。获取与规格可后续补。
7. ✅ **灵能武装**已定（见 1.19）：护甲以灵能形态存储、驱动实体化，全职业通用；分内储（灵能充裕者）/ 外储（灵能容器，形态不限）两路。**梅丹佐走纯灵能内储**（灵能充裕；且胸口已有萨拉塔斯匕首纹身，避免与胸口容器位置冲突）。
8. ✅ **恶魔工艺水晶**已定（见 1.20）：DH 制式解控道具；隐藏限制 = 施控者须被牵制水晶才生效。E-10 伏笔待解救剧情兑现。
