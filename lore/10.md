## 二、主角团（Main Party，4 人）

### 1. 梅丹佐·虚影（Metatron，梅塔特隆）— 虚空编织者

- **种族**：虚空精灵（银月城贵族出身）
- **职业**：虚空编织者（Voidweaver = 虚空法师）
- **力量属性**：虚空（Void）
- **队伍定位**：远程法系输出（法系主炮）
- **外观**：面具（抑制体内虚空灵能外泄）；护甲为"虚空的星界执政官"，经幽暗之心重塑升级（光翼已消失·详见 `01` §一）
- **武器**：六枚虚空法球（类似辛德拉黑球）+ 一把月刃「虚空之刃」（仿 LOL 黛安娜月刃工艺）
- **生平**：
  1. 银月城贵族、高阶魔导师，为人谦和，常救助贫民窟居民，与贫民窟的蓝眼女血精灵**埃尔**结下深厚交情，并向远行者引荐她
  2. 魔法造诣极高，唯独对奥术不感兴趣；大地裂变随队讨伐暮光堡垒后对虚空产生兴趣
  3. 在银月城秘密研究虚空魔法被高层发现、遭驱逐
  4. 流浪至诅咒之地，借黑暗之门空间能量撕开虚空裂隙、吸入虚空乱流
  5. 为求生吸收虚空灵能，醒来后置身**乌尔纳（星际）**，发现萨尔纳加星际舰**观星者号**并借舰回艾泽拉斯
  6. 在瓦尔完成委托后，奇点特勤以萨尔纳加正版单人虚空舰「**虚空追觅者**」作抵押报酬，成为其个人飞行坐骑（昵称「星裁者」）

**技能组（详见 `07` §二）**：

| 技能                     | 类型   | 关键机制                                               |
| ---------------------- | ---- | -------------------------------------------------- |
| 虚空冲击 Void Blast        | 基础   | 引导虚空灵能发起一次攻击                                       |
| 心灵震爆 Mind Blast        | 控制   | 打断对方吟唱 / 引导；晕眩、混乱、生理恶心，效果随时长随精神抗性降低                |
| 虚空洪流 Void Torrent      | 持续   | 引导 1–3 秒，自身 + 精神双重伤害、**无视抗性**；被打断则灵能透支反噬晕眩         |
| 虚空齐射 Void Volley       | 范围   | 六法球扩散最多 **36 枚**弹幕；命中生成**虚空印记**（2–5 秒，圣光可驱散，使敌方现形） |
| 虚空形态 Void Form         | 终极   | 持续 30–60 秒，**所有技能无视抗性**；引爆虚空印记造成晕眩；结束虚弱需能量药剂       |
| 虚空湮灭 Void Obliteration | 终极   | 过载六法球生成虚空传送门、持续落下坍缩之星；法球用后空灵需充能                    |
| 虚空法球 Void Orbs         | 核心道具 | 共六枚；附敌吸收虚空灵能补给；可生成小型黑洞聚敌 / 隔敌                      |
| 虚空之刃 Void Blade        | 近战武器 | 黛安娜月刃工艺；**无视护盾与虚空抗性**，补齐近身能力                       |

**召唤留坑（已决议）**：梅丹佐**不添加**召唤技能（见 `07` §一·1.3 / 待确认 #3）——曾想做虚空裂隙弹幕，与虚空齐射重合故弃；队伍已有马蒂考尔、骨语女士召唤单位。

### 2. 埃尔（Er）— 噬灭恶魔猎手 · 虚痕流派

- **种族**：血精灵（Blood Elf）
- **职业**：噬灭恶魔猎手（Devourer Demon Hunter）· 虚痕流派（英雄天赋）
- **力量属性**：虚空（底色）/ 混沌（邪能）
- **队伍定位**：近战高机动突进手
- **外观**：深灰兜帽 + 深灰面罩，潜行者风格幻化；护甲为伊利达雷"欺诈者的桂冠"（详见 `01` §二）
- **特征（重要）**：眼睛是**高等精灵的蓝色**，非血精灵因邪能沾染的绿色——在一个几乎全员绿眼的种族里，她从未被邪能碰过，后走虚空而非邪能之路
- **武器**：双短刃
- **生平**：
  1. 银月城贫民窟出身、无姓氏；自幼练就潜行者技能
  2. 被梅丹佐引荐进远行者，但弓箭天赋太差，由潜行者队接纳
  3. 梅丹佐被驱逐后离城寻他；旅途结识术士马蒂考尔，结伴做赏金猎人
  4. 诺森德时期被**噬心魔**占据身体、失去意志；马蒂考尔将其囚禁带至外域纳格兰，寻得**奥图里斯**（伊利达雷）授法
  5. 学会操纵虚空之力，成为噬灭 DH，战斗风格保留潜行者高机动底子

**技能组（详见 `07` §三）**：

| 技能                   | 类型    | 关键机制                              |
| -------------------- | ----- | --------------------------------- |
| 虚痕战斗技艺 Voidscar Arts | 体系    | 无冕者 + 伊利达雷技巧融合，自成一派               |
| 眼棱 Eye Beam          | 招牌    | 幻影引导邪能 + 虚空射线；击退目标（看护盾）、灼烧对方灵能    |
| 暗影打击 Shadow Strike   | 位移/爆发 | 锁定后瞬移至目标身边（最远约 2.5 米，障碍终止）用双刃攻击一次 |
| 根除 Uproot            | 范围/紊乱 | 双刃横扫；令目标混乱、灵能紊乱（引导变长、回灵变慢）        |
| 混乱风暴 Chaos Storm     | 终极    | 身周生成涡流，对周围持续造成伤害                  |

### 3. 马蒂考尔（Matticaul）— 恶魔使徒

- **种族**：德莱尼（Draenei）
- **职业**：恶魔使徒（Demon Apostle，自创体系）
- **力量属性**：混沌（Chaos / 邪能）
- **队伍定位**：诅咒辅助 / 增益；**大恶魔形态 = 主坦**
- **护甲**：伊利达雷废案"扭曲恶魔的灾厄"，可随亚巴顿恶魔形态自动变幻（原"术士 T6 套装"作废·详见 `01` §三）
- **武器**：一把匕首
- **生平**：
  1. 阿古斯落难后追随先知维伦流浪；德拉诺时期任德莱尼占星师（空间魔法底子）
  2. 兽人进攻时与维伦走散；耐奥祖引爆德拉诺时以占星术传送至**庇护之地（暗黑）**
  3. 被一名术士所救，后发现对方想将其献祭给魔神**巴尔**；杀之并吸收其大恶魔**亚巴顿**之力 → 可短暂化恶魔
  4. 后被奈非天杀死 → 复活于扭曲虚空 → 重返艾泽拉斯；救下被噬心魔附身的埃尔

**技能组（详见 `07` §四）**：

| 混乱箭 Chaos Bolt       | 基础        | 引导混沌之力造成伤害                        |
| 灾厄 Calamity          | 范围/现形     | 生成恶魔之眼攻击区域目标；使周围目标现形、灵能紊乱         |
