# 小说设定集 · 06 载具与主舰规格书（新版）

> 2026-09-07 重设：虚空追觅者改为梅丹佐个人飞行坐骑，团队移动基地改为**观星者号**。四人飞行坐骑统一为星际/跨界小型载具，淘汰旧版"滑行板"。

## 一、总则：飞行坐骑规则

| 项目 | 规则 |
|---|---|
| 定位 | 仅供主角团四人个人使用的飞行/地面载具 |
| 地面模式 | 支持反重力滑行，可在地面使用 |
| 跃迁能力 | **无**——不能跨位面、跨星域航行 |
| 太空航行 | 可在大气层外短途航行（如艾泽拉斯 ↔ 月球级别） |
| 作战能力 | **仅自卫级别**——简单火力，用于脱离/拦截，不能打舰队战 |
| 与主舰关系 | 四人坐骑平时停放在**观星者号**机库内；长距离航行由观星者号负责 |

## 二、主舰：观星者号

### 2.1 基础设定

- **来源**：远古萨尔纳加制造的星际航行舰；属最晚批次生产，尺寸型号均偏小
- **停产原因**：艾蒙消灭剩余萨尔纳加后，生产线停产；观星者号未投入使用，封存于乌尔纳虚空之中
- **发现者**：梅丹佐误入虚空乱流后，在乌尔纳发现此舰
- **定位**：影财团移动基地 / 团队大本营
- **视觉参考**：星灵母舰（俗称"妈妈船"，即 Protoss Mothership）造型风格——巨型悬浮舰体、环绕式锐角结构
- **核心乘员**：迪门修斯本体在观星者号内休眠（此前设定为"虚空追觅者号"，现已迁移至此）
- **待机位置**（作者 2026-09-24 定）：日常＝艾泽拉斯大气层内高空悬停 **或** 地表停靠，**主角团偏好地表停靠**；近地轨道/深空为特殊情形。详见 `10` §四。

### 2.2 舰内结构（四层，自上而下）

观星者号由外壳至内部分为主体四层，**自上而下**依次排列：

#### 第一层 · 生活区（顶层）
- **居住舱**：主角团四人（梅丹佐 / 埃尔 / 马蒂考尔 / 骨语女士）与舰上配角（迪门修斯、林普、莉莉丝、马林、迈尔斯·科林、奥·巴马）的私人房间
- **生态舱**：梅丹佐的宠物虚空兔**萨拉兔斯**饲养于此（独立生态循环，模拟虚空环境）
- **马林图书馆**：由马林构筑并管理的藏书空间，位于本层
- **恢复室 / 月亮井**：马林 + 迪门修斯研发，驻舰疗愈设施
- **管家 / 财务室**：迈尔斯·科林的办公与账房
- **交易舱 / 奥·巴马客房**：奥·巴马的客房兼对外交易间

#### 第二层 · 休闲区
- **对战模拟室**：类魔兽"伤害假人房"的模拟训练场；既可打磨输出循环，也可供主角团四人互相切磋对练
- **酒吧**：由埃尔专门改造，林普常驻调酒、莉莉丝负责服务
- **观景客厅**：360° 无死角全景客厅，主角团闲暇时喜欢在此观赏星空夜景

#### 第三层 · 驾驶区
- **指挥甲板 / 驾驶舱**：主舰航行与跃迁操作中枢
- **舰内走廊**：连接各舱室的交通干道
- **生态区**：主角团的**陆地坐骑**饲养区（虚翼龙鹰 / 心契元狼 / 伊利达雷魔犬 / 重装凋腐荒牛）

#### 第四层 · 备战区（底层）
- **飞行坐骑停靠坞**：主角团四台**个人飞行坐骑**（凤凰战机 / 虚空追觅者 / 哨兵 / 海盗船）停放与维护区

### 2.3 核心能力

| 能力 | 说明 |
|---|---|
| **跨位面/星域航行** | 主舰级长距离跃迁 |
| **隐形** | 扭曲周围空间立场，肉眼不可观测；可被魔法、灵能感知 |
| **黑洞** | 制造小型引力场，将区域内单位拉入；持续时间与能量消耗成正比 |
| **瓦解光束** | 8 门集束炮，中远程攻击；可瓦解能量护盾与物理护盾；对有能量抗性（奥术/虚空/圣光/元素）目标伤害降低 |
| **能量转化** | 三颗能量核心吸收宇宙以太物质，转化为舰体所需能量 |

### 2.4 自设偏差

| 项目 | 官方设定 | 本书设定 |
|---|---|---|
| 观星者号原型 | 视觉参考为星灵母舰**妈妈船（Protoss Mothership）**；早期草稿曾参考亚顿之矛 | 本书中设定为萨尔纳加制造的最晚批次星际舰，命名"观星者号"，外观取星灵母舰造型 |
| 虚空追觅者 | 泽拉图个人虚空舰 | 本书中改为梅丹佐**个人飞行坐骑**，不再作为团队主舰 |

## 三、个人飞行坐骑

### 3.1 埃尔 — 凤凰战机（Phoenix）

- **简称**：凤凰
- **来源**：通过奥·巴马在星灵处**分期贷款**购入
- **外观**：原为星灵标志性的金色，埃尔嫌太高调，委托二手改装商改为**灰色与银色**
- **趣闻**：改装商手艺欠佳，制冷系统大不如前；埃尔曾在塔纳利斯执行观察任务时，在座舱内**中暑**
- **定位**：高机动性空优机，与埃尔潜行者出身的突进风格匹配

### 3.2 梅丹佐 — 虚空追觅者（Void Seeker）

- **简称**：星裁者（作者喜欢这个旧名，保留作昵称）
- **来源**：梅丹佐在瓦尔完成委托后，奇点特勤因经费不足，用此舰作为报酬抵押
- **官方误认**：奇点特勤以为是侏儒/地精科技的仿制品；实则为**萨尔纳加正版星舰**
- **定位**：梅丹佐个人专属飞行坐骑，单人舰规格
- **召唤方式（作者指定）**：梅丹佐抬手"按下虚空中不存在的开关"→ 身前空气塌缩出一点黑 → 旋转裂隙收拢、紫黑流光翻卷 → 能量自虚空矩阵后方汇聚凝结 → 实体从虚空中显形（致敬星灵折跃建造 Warp-in，但**光为紫色、非星灵蓝绿**）。详见 `小说正文/E-22` §十四。
- **视觉锚点**：梭形舰体、金属冷泽、锐利龙骨收尖；折跃辉光为**紫**（⚠️ **绿光改紫**：用户原外观图标绿光，本书统一改紫，呼应梅丹佐虚空体质与萨拉塔斯匕首纹身）。
- **备注**：梅丹佐本人对此舰"嗤之以鼻"的吐槽，反而坐实了他捡漏

### 3.3 马蒂考尔 — 哨兵（Sentinel）

- **来源**：马蒂考尔在克哈某赌场参加**大胃王比赛**，1 小时内吃完 385 个巨无霸汉堡
- **获奖争议**：赌场内定冠军为**牛头人机枪兵**（星际 2 彩蛋单位），拒绝兑付奖品
- **获取方式**：马蒂考尔直接抢走哨兵战机，返回艾泽拉斯后在热砂港找地精改装
- **改装理由**："去科普露星区执行任务被人认出来很难办"——埃尔补刀："难办？那就不办了！"
- **视觉**：原型为星际1 侦察机（Scout / 侦察机）——**橙色**小型战机造型（⚠️ 作者 2026-10-10 定：**橙色**，"金色太扎眼了"；"**小型**"＝小型机（机型），书中描写"**修长**"＝机身长度，二者不冲突）；热砂港地精改装后叠加地精机械与燃烧地狱（混沌）风味
- **定位**：马蒂考尔的地精风味载具，兼具燃烧地狱（混沌）元素与星灵科技外壳

### 3.4 骨语女士 — 海盗船（Corsair）

- **原始订单**：骨语女士向虚灵大盗拉法姆订购的是魔兽坐骑**惊魂者号（The Dreadwake）**——一艘被未知深海章鱼脸神明托举的飞行海盗船
- **发货错误**：拉法姆没看备注，直接从**塔达林（Tal'darim，星灵的一支）**处偷来一艘星灵海盗船
- **尾款处理**：骨语女士拒绝结尾款；拉法姆盗亦有道，承认是自己失误，放弃尾款
- **定位**：死亡系亡灵海盗美学与星灵科技的混搭载具
